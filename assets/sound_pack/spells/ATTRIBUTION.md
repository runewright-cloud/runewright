## Licence taken, and licence shipped

Taken under **CC BY-SA 3.0**. Shipped under **CC BY-SA 4.0**.

Rationale (full reasoning in `docs/SPELL_SOUND_PACK_PLAN.md` §1 "Why ShareAlike is not a
problem here"): unlike the painterly-icon transcode, this pack's processing (mono
downmix, loudness normalization, silence trim) goes beyond the "modifications as are
technically necessary" that BY-SA 3.0 §3 permits — so the derived pack **is** an
Adaptation, and ShareAlike attaches to it. BY-SA 3.0 §4(b) explicitly permits licensing
an Adaptation under "a later version of this License with the same License Elements," so
the derived pack ships as CC BY-SA 4.0 — the same licence Runewright's own creative
assets already use (`LICENSE-ASSETS`). Confirmed by Soren 2026-08-07 (plan §2 D-1).

## Modifications made

Applied uniformly to every source file, no exceptions:

- Downmixed to mono, encoded as Ogg Vorbis (`-q:a 2`).
- Two-pass `loudnorm` to I = −16 LUFS, TP = −1.5 dBTP, LRA = 11.
- Leading silence trimmed.

This is a real Adaptation, not a format-only transcode — see the rationale above. If this
statement ever changes (e.g. any pitch-shifting, mixing two clips, or other creative
editing), the modification note here and in `manifest.json` must be updated to match.

## Regeneration

The derived assets in this directory (`*.ogg`, `manifest.json`) are generated by
`scripts/build_sound_pack.py` from the raw source files at `assets/audio/spells/`
(gitignored — see `docs/SPELL_SOUND_PACK_PLAN.md` D-2, and note per Finding 1 that many
of those source files are actually RIFF WAV despite the `.ogg` extension; the build
script sniffs magic bytes, never the extension). To reproduce from scratch:

1. Download the archive above; verify it against its SHA-256.
2. Unzip into `assets/audio/spells/`.
3. Run `python3 scripts/build_sound_pack.py`.

This file (`ATTRIBUTION.md`) is hand-authored and is not overwritten by the build script.
