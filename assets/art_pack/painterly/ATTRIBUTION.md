## Licence selected

**CC BY-SA 4.0** — https://creativecommons.org/licenses/by-sa/4.0/

Rationale (full reasoning in `docs/SPELL_ART_PACK_PLAN.md` §1–§2 D-1): a lossy format
transcode is a "technical modification" under §2(a)(4) of the licence, which explicitly
"never produces Adapted Material" — so ShareAlike (§3(b)) never attaches to this pack.
Taking the whole pack under BY-SA 4.0 also unifies it with Runewright's own creative
assets, which CLAUDE.md already licenses CC BY-SA 4.0.

## Modifications made

Applied uniformly to every source `.png`, no exceptions:

- Re-encoded from 256×256 PNG to 256×256 lossy WebP (`quality=82, method=6`), RGB.
  Every source icon in this pack is fully opaque — verified programmatically before
  building the pack (261 are plain RGB with no alpha channel at all; the remaining 141
  carry an RGBA plane but it is uniformly 255/opaque everywhere; none has any actual
  transparency) — so there is no alpha channel to preserve, and none is claimed.
- **No resizing, no cropping, no recolouring, no compositing, no pixel-level editing.**
- Filenames preserved verbatim from the source archives (`<subject>-<colour>-<level>`).

If this statement ever becomes false — any compositing (e.g. baking a decorative frame
into an icon) or repainting — the result is Adapted Material under the licence and must
itself be distributed under CC BY-SA 4.0 (already true for this project's own assets, so
this is a note for correctness, not a new obligation).

## Regeneration

The derived assets in this directory (`*.webp`, `manifest.json`) are generated by
`scripts/build_art_pack.py` from the raw source PNGs at `assets/art/` (gitignored —
see `docs/SPELL_ART_PACK_PLAN.md` D-2). To reproduce from scratch:

1. Download the four archives listed above; verify each against its SHA-256.
2. Unzip each into `assets/art/painterly-spell-icons-<N>/`.
3. Run `python3 scripts/build_art_pack.py`.

This file (`ATTRIBUTION.md`) is hand-authored and is not overwritten by the build script.
